# mw-hbg/.github

Default files for all repositories of [mw-hbg](https://github.com/mw-hbg) that
have no own version: issue forms (`.github/ISSUE_TEMPLATE/`), the security
policy ([`SECURITY.md`](SECURITY.md)) and the sponsor button
([`.github/FUNDING.yml`](.github/FUNDING.yml)). Shared workflows:
[mw-hbg/workflows](https://github.com/mw-hbg/workflows).

Standarddateien für alle Repositories von mw-hbg ohne eigene Fassung:
Issue-Formulare, Sicherheitsrichtlinie und Sponsor-Knopf. Gemeinsame Workflows:
[mw-hbg/workflows](https://github.com/mw-hbg/workflows).

# mw-hbg/.github

Default files for all repositories of [mw-hbg](https://github.com/mw-hbg) that
have no own version: issue forms (`.github/ISSUE_TEMPLATE/`) and the security
policy ([`SECURITY.md`](SECURITY.md)). Shared workflows:
[mw-hbg/workflows](https://github.com/mw-hbg/workflows).

Standarddateien für alle Repositories von mw-hbg ohne eigene Fassung:
Issue-Formulare und Sicherheitsrichtlinie. Gemeinsame Workflows:
[mw-hbg/workflows](https://github.com/mw-hbg/workflows).
